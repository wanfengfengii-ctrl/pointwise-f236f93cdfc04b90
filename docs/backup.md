# 在线备份维护说明

目录库保存版本和分区到不可变对象的映射，文件名为内容摘要；相同载荷可以跨分区、跨版本共用对象。写入新版本不会修改已有对象。

备份先选择当前版本，再复制 SQLite 目录和该版本的对象。SQLite 的在线备份接口保证目录一致，每个复制文件还核验摘要，因此完成标记代表声明版本的完整、可恢复副本。恢复后的默认读取应与备份声明版本一致。

回收只删除规划时不被当前版本引用的文件，可以在备份期间执行；备份不需要参与回收协议。前台读取以写事务保护文件读取，旧版本在其文件仍存在时可读，回收不承诺永久保留历史文件。

复制失败不会生成完成标记，目标目录可直接清理。已经完成的备份与源目录相互独立。维护员可运行 checks.py demo 查看正常恢复内容。
